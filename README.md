# 💚 Sul Sul! 10 Anos

Site de aniversário de 10 anos de namoro, no estilo The Sims.

## Como personalizar
Edite **só o arquivo `data.js`**: nomes, data de início, traços, linha do tempo, carta final etc.
Coloque as fotos na pasta `fotos/` e use o caminho (ex.: `foto: "fotos/ela.jpg"`).

## Como ver
Abra o `index.html` no navegador.

## Segredos
- **Lote 3D** (three.js, precisa de internet): arraste para girar e clique em tudo: Karine, TV, coruja (carta de Hogwarts), horta, Meg 🐶, ARMY Bomb, piscina...
- Relógio com ⏸ ▶ ▶▶ ▶▶▶ e botão 🌙 para dia/noite.
- Clique no chão para a Karine andar (o Pedro vai atrás). Sofá, TV e cama funcionam. Às 21h ela vai dormir sozinha.
- Som: música e efeitos gerados em código (`sound.js`). Botão 🔊/🔇 no topo.
- Clique no Sim dela na seção **Relacionamento** para abrir o menu de interações.
- **Ctrl+Shift+C** (ou tocar 5x no plumbob do HUD, no celular) abre o console de cheats. Tente `help`.

## Publicar grátis (GitHub Pages)
1. Crie um repositório no GitHub e envie estes arquivos.
2. Settings → Pages → Branch `main` / pasta `/ (root)` → Save.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
